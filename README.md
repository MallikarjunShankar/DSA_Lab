# DSA Lab Experiments

This repository contains the implemented C programs for Data Structures and Algorithms (DSA) lab work.

## Implemented Experiments

The following experiments are already implemented and titled in their source comments:

- EXP1.c — IMPLEMENTATION OF STRUCTS
- EXP2.c — IMPLEMENTATION OF STRUCTS USING POINTERS
- EXP3.c — IMPLEMENTATION OF MATRIX MULTIPLICATION - DYNAMIC MEMORY ALLOCATION
- EXP4.c — ARRAY IMPLEMENTATION OF LIST
- EXP5.c — IMPLEMENTATION OF LINKED LIST
- EXP6.c — IMPLEMENTATION OF DOUBLY LINKED LIST

Other files in the folder are not listed because they are not implemented or do not have a title comment at the top.

## How to Run

Compile any implemented experiment with GCC:

```bash
gcc EXP6.c -o EXP6
./EXP6
```

## Purpose

This repo is intended for:

- learning basic and advanced data structures
- practicing algorithm implementation
- preparing for DSA lab assignments and viva
